# Sanjay Kumar Bejjanki — Portfolio Website

A responsive personal portfolio site showcasing my work as a Python Developer
and AI/ML Engineer, built entirely with vanilla HTML, CSS, and JavaScript
(no frameworks).

🔗 **Live site:** https://sanjaykumarbejjanki.github.io/portfolio-website/

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Scroll-triggered reveal animations
- Animated skill bars and stat counters
- Client-side contact form validation (vanilla JS, no libraries)
- Downloadable resume (PDF)
- Accessible navigation with keyboard focus states

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties, Grid, Flexbox, animations
- **JavaScript (ES6+)** — DOM manipulation, IntersectionObserver, form validation
- **Fonts:** Fraunces, JetBrains Mono, Inter (Google Fonts)

## Project Structure

```
├── index.html       Main HTML file
├── css/style.css     Stylesheet
├── js/script.js      JavaScript logic
└── assets/           Resume PDF and images
```

## Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/SanjaykumarBejjanki/portfolio-website.git
   ```
2. Open the folder in VS Code.
3. Install the "Live Server" extension.
4. Right-click `index.html` → **Open with Live Server**.
